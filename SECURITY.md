# Security Policy

## Reporting a Vulnerability

We take the security of Zyrix Bot seriously. If you discover a security vulnerability, please report it to us immediately. We appreciate your efforts to responsibly disclose your findings and will work with you to address them promptly.

**Please do NOT disclose vulnerability details publicly.**

To report a vulnerability, please send an email to [security@imzyrix.com](mailto:security@imzyrix.com) with the following information:

*   A clear and concise description of the vulnerability.
*   Steps to reproduce the vulnerability.
*   The potential impact of the vulnerability.
*   Any suggested mitigations or fixes (if applicable).

We will acknowledge your report within 48 hours and provide a more detailed response within 7 days. We kindly request that you give us a reasonable amount of time to address the issue before any public disclosure.

## Supported Versions

The following versions of Zyrix Bot are currently supported for security updates:

| Version | Supported |
| :------ | :-------- |
| Latest  | Yes       |
| Older   | No        |

We encourage all users to keep their bots updated to the latest version to ensure they benefit from the most recent security patches.
