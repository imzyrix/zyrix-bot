## ⚠️ Status: Under Work

**Zyrix Bot is currently under active development.** While many features are fully functional, some systems (such as the Music module) are undergoing maintenance. We are constantly updating and refining the bot to provide the best experience possible.

## About The Project

Zyrix Bot is a powerful, feature-rich Discord bot built to handle everything your server needs. With over 350 commands across 87 loaded cogs, it provides robust security, advanced automoderation, interactive AI, and a suite of 12 standalone games.

### Built With

Zyrix Bot is built on a modern, scalable Python stack:

*   **Language:** Python 3.14
*   **Framework:** [discord.py](https://discordpy.readthedocs.io/) (Hybrid commands: Prefix & Slash)
*   **Database:** SQLite via `aiosqlite` (30+ separate `.db` files for modularity)
*   **Web Server:** Flask (Keep-alive server)
*   **AI Integration:** Groq API (`mixtral-8x7b-32768` model)
*   **Music:** Wavelink + Lavalink

## Core Features

Zyrix Bot offers a massive suite of features designed for server management and user engagement:

*   **🛡️ Advanced Security**: 15-point Antinuke system, whitelist/unwhitelist, and emergency modes.
*   **🤖 Automoderation**: Comprehensive filters for spam, links, caps, and mass mentions with automated punishment systems.
*   **🧠 AI Chatbot**: Integrated Groq AI with internet access, smart mention responses, and context history.
*   **🎮 12 Standalone Games**: Including Blackjack, Wordle, Chess, 2048, and more.
*   **🔨 Moderation & Logging**: Full suite of mod tools and advanced logging across 30+ event types.
*   **🎟️ Utility & Roles**: Ticket panels, reaction roles, leveling, and custom welcome systems.
