# Contributing to Zyrix Bot

We welcome contributions to Zyrix Bot! Whether you're reporting a bug, suggesting a new feature, or submitting code, your help is greatly appreciated.

## How to Contribute

1.  **Reporting Bugs**: If you find a bug, please open an issue on our [GitHub repository](https://github.com/imzyrix/zyrix-bot/issues) with a clear description of the bug, steps to reproduce it, and expected behavior.
2.  **Suggesting Features**: Have an idea for a new feature? Open an issue on GitHub to discuss it with the community and maintainers.
3.  **Submitting Code**: While this repository is primarily for documentation, if you have code contributions for the bot itself, please refer to the main development repository (link to be provided).
