# Commands Reference

This document provides a comprehensive list of all commands available in Zyrix Bot, categorized for easy navigation.

## General Commands

*   `!help`: Displays a list of all available commands or detailed information about a specific command.
*   `!ping`: Checks the bot's latency.

## Moderation Commands

*   `!kick <user> [reason]`: Kicks a user from the server.
*   `!ban <user> [reason]`: Bans a user from the server.
*   `!mute <user> [duration]`: Mutes a user for a specified duration.

## Utility Commands

*   `!userinfo [user]`: Displays information about a user.
*   `!serverinfo`: Displays information about the server.
*   `!weather <location>`: Shows weather information for a given location.

## Fun Commands

*   `!8ball <question>`: Answers a yes/no question.
*   `!meme`: Displays a random meme.
