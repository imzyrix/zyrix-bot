# Commands Reference

This document provides a comprehensive list of all commands and features available in Zyrix Bot, categorized for easy navigation. Zyrix Bot currently boasts **350 commands** (261 prefix commands and 89 slash commands) across its various modules.

## 🛡️ Security & Antinuke Commands

These commands and features are designed to protect your server from raids and malicious activities.

*   **Antinuke System**: Comprehensive protection against ban/kick, channel/role management, webhooks, pruning, everyone pings, bot additions, integrations, member updates, and guild updates.
*   **Whitelist / Unwhitelist**: Manage trusted users or roles that bypass security checks.
*   **Extra Owner System**: Assign additional owners with elevated permissions.
*   **Emergency Mode**: Instantly lock down your server during an attack.

## 🤖 Automoderation Commands

Commands and features for automatic content filtering and moderation.

*   **Anti Spam**: Prevents message spam.
*   **Anti Caps**: Filters excessive use of capital letters.
*   **Anti Link**: Blocks unwanted external links.
*   **Anti Invites**: Prevents Discord invite links.
*   **Anti Mass Mention**: Curbs mass mentions.
*   **Anti Emoji Spam**: Limits excessive emoji usage.
*   **Anti NSFW Links**: Filters out NSFW content links.
*   **Punishment System**: Configurable automatic Mute, Kick, or Ban actions.
*   **Ignore Roles/Channels**: Define exceptions for automod rules.
*   **Automod Logging**: Logs all automod actions.

## 🔨 Moderation Commands

Manual moderation tools for server administrators.

*   `!ban <user> [reason]`: Bans a user.
*   `!unban <user_id>`: Unbans a user.
*   `!kick <user> [reason]`: Kicks a user.
*   `!mute <user> [duration]`: Mutes a user.
*   `!unmute <user>`: Unmutes a user.
*   `!warn <user> [reason]`: Warns a user.
*   `!lock [channel]`: Locks a channel.
*   `!unlock [channel]`: Unlocks a channel.
*   `!hide [channel]`: Hides a channel.
*   `!unhide [channel]`: Unhides a channel.
*   `!role <user> <role>`: Manages user roles.
*   `!jail <user> [duration]`: Jails a user.
*   `!timeout <user> [duration]`: Times out a user.
*   `!snipe`: Retrieves the last deleted message.
*   **Message tools**: Various utilities for message management.
*   **Top role check**: Checks a user's highest role.
