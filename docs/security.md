# Security & Automoderation

Zyrix Bot provides a robust set of security and automoderation features to keep your Discord server safe and clean.

## 🛡️ Antinuke System

Our advanced Antinuke system offers 15 layers of protection against malicious activities, preventing server raids and unauthorized changes. Each protection can be configured to your server's needs.

### Protected Events:

*   **Ban/Kick Protection**: Prevents mass banning or kicking of members.
*   **Channel Management**: Protects against unauthorized channel creation, deletion, and updates.
*   **Role Management**: Safeguards against unauthorized role creation, deletion, and updates.
*   **Webhook Protection**: Prevents malicious webhook creation.
*   **Prune Protection**: Limits mass member pruning.
*   **Everyone Ping Protection**: Prevents abuse of `@everyone` or `@here` pings.
*   **Bot Add Protection**: Restricts unauthorized bot additions.
*   **Integrations Protection**: Secures server integrations.
*   **Member Update Protection**: Monitors and prevents suspicious member updates.
*   **Guild Update Protection**: Protects against unauthorized server setting changes.

### Additional Security Features:

*   **Whitelist / Unwhitelist System**: Designate trusted users or roles that bypass certain security checks.
*   **Extra Owner System**: Assign additional trusted owners with elevated permissions.
*   **Emergency Mode**: Instantly lock down your server during an attack.

## 🤖 Automoderation

Zyrix Bot's automoderation features help maintain a positive environment by automatically detecting and acting upon undesirable content.

### Automod Filters:

*   **Anti Spam**: Detects and mitigates message spam.
*   **Anti Caps**: Prevents excessive use of capital letters.
*   **Anti Link**: Blocks unwanted external links.
*   **Anti Invites**: Prevents posting of Discord invite links.
*   **Anti Mass Mention**: Curbs mass mentions of users or roles.
*   **Anti Emoji Spam**: Detects and limits excessive emoji usage.
*   **Anti NSFW Links**: Filters out links to Not Safe For Work content.

### Automod Actions:

*   **Punishment System**: Configure automatic Mute, Kick, or Ban actions per event.
*   **Ignore Roles/Channels**: Specify roles or channels where automod rules are not applied.
*   **Automod Logging**: All automod actions are logged to a designated channel for review.
