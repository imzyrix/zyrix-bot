# Configuration Guide

This guide explains how to configure Zyrix Bot to best suit your server's needs. Zyrix Bot offers various customization options, accessible through specific commands or a web dashboard (coming soon).

## Prefix

The default prefix for Zyrix Bot commands is `!`. You can change this using the `!setprefix <new_prefix>` command.

## Permissions

Zyrix Bot uses Discord's native permission system. Ensure the bot has the necessary permissions in your server for all features to function correctly. Specific command permissions can be managed through Discord's role settings.

## Feature Toggles

Many features can be enabled or disabled on a per-server basis. Use the `!settings` command to view and modify these settings.
